# 🌊 JalMap Live - Kolkata

A live app to see which roads in Kolkata are waterlogged when it rains.

### Problem
During the monsoon in Kolkata, no one knows which road is flooded. People go out and get stuck in the water.

### Solution
On JalMap, anyone can give a live report of their area - whether the road is Clear or Waterlogged.
On the map, a green dot means the road is clear, and a red dot means it is waterlogged.

### Features
- Live Map of Kolkata
- User Report System - Waterlogged / Clear / Knee-deep water
- Safe Route Suggestion
- Rain Update (mm/hr)

### Tech Used
- Python
- Streamlit
- Folium Map
- Pandas
